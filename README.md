# Create: The Air War

Military equipment, aircraft weapons, guided missiles and camera systems for
Minecraft 1.21.1 on NeoForge.

## Requirements

- Java 21
- NeoForge 21.1.219
- Create 6.0.9
- Sable 1.0.5 and Sable Companion 1.4.2
- Create Aeronautics 1.0.2 (bundled build dependency in `libs/`)

## Build

Windows: `gradlew.bat build`

Linux/macOS: `./gradlew build`

The built mod is written to `build/libs/`.
